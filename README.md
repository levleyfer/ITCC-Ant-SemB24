# ITCC Cloud Computing Project

This repository contains exercises, homework, and a final project for an Introduction to Cloud Computing course.

## Technologies

- Python
- Google Colab
- Firebase
- Pandas / NumPy
- Matplotlib
- BeautifulSoup
- NLTK
- ipywidgets

## Project Focus

The project demonstrates cloud-based data processing, Firebase database usage, web scraping, data visualization, and interactive notebook applications.

## Contents

- `Exercises/` – course practice notebooks
- `HW1/`, `HW2/`, `HW3/` – homework assignments
- `Project/` – final project notebook, report, and presentation
